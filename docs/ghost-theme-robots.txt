# robots.txt for the Ghost origin (ghost-production-198e.up.railway.app)
# ----------------------------------------------------------------------
# Upload into the Ghost theme root so it overrides Ghost's stock default.
# This is NOT tokenwisdom.org's robots.txt — that one is managed by
# Cloudflare (AI Crawl Control) and is not served out of docs/.
#
# Why this file exists: the Ghost instance serves a complete copy of every
# post, and it emits no canonical tags (0/285 posts carry canonical_url).
# Left alone, it competes with tokenwisdom.org for the same content in
# search results. tokenwisdom.org is canonical; this origin is the CMS.
#
# The proper fix is canonical tags pointing at tokenwisdom.org — if those
# ever get set in Ghost, relax the blanket Disallow below to just the
# operational paths, so crawlers can read the canonical instead of being
# shut out. Blocking crawl means a URL can still be indexed bare, without
# content; a canonical is the stronger signal.

# ── Search crawlers ────────────────────────────────────────────────────
# Keep the duplicate origin out of search entirely.

Disallow: /
