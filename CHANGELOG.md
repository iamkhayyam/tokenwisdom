# Changelog

## 2026-06-14 — Archive: four ways to explore

Reworked `docs/archive.html` (generated by `render_archive()` in `generate_site.py`)
from a flat year-grouped list into a multi-view explorer. A toggle bar switches
between four synchronized views, all driven by one embedded data set (`POSTS` +
`TAGNAMES`, built from `data/all_posts.json`).

- **List** — the chronological list, now with a per-year **sticky header** that
  folds the year label, a 12-month mini-calendar, and the cluster filters into a
  single bar. Each header is bounded by its `position:relative` year-section, so
  scrolling into the next year shoves the current header up and locks the new one
  in (CSS-sticky handoff, no scroll listener). Month pills jump to that month;
  cluster chips filter across all years.
- **Heatmap** — years × 12 months, each cell tinted by its dominant cluster and
  shaded by post count; hover for counts, click to jump into the list.
- **Timeline** — all 267 posts as dots on a continuous 2013→2026 axis, stacked
  per month and colored by cluster; click a dot to open the post.
- **Clusters** — topic tags as spiral-packed bubbles sized by post count and
  colored by dominant cluster; click a bubble to filter the list by that tag.

Cluster filtering uses real Ghost tag slugs (`a-closer-look`, `worthafortune`,
`dear-______-letters`, else Featured) rather than the single displayed label, so
every essay is correctly classified.
